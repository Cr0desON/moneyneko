# 🐱 MoneyNeko

**MoneyNeko** — это интерактивное веб-приложение, созданное специально для студентов, чтобы помочь им освоить и прокачать навыки финансовой грамотности в увлекательном игровом формате. 

## 🎯 О проекте
Изучение финансов не должно быть скучным! В MoneyNeko сухая теория подкрепляется практикой, а главным спутником пользователя становится интерактивный маскот — кот, чье настроение и благополучие напрямую зависят от финансовых решений игрока.

**Ключевые возможности:**
*   **Образовательные материалы и тесты:** Полноценные обучающие модули по основам финансовой грамотности.
*   **Интерактивные тренажеры:** Практические мини-игры, моделирующие реальные жизненные и финансовые ситуации.
*   **Живой маскот:** Эмоции кота динамически меняются в зависимости от заработанных баллов и успешности прохождения курсов.
*   **Система достижений:** Ежедневные стрики (награды за регулярный вход), начисление XP (опыта) и лидерборд для соревнований между студентами.

## 🛠 Стек технологий
*   **Ядро:** WordPress (PHP, MySQL)
*   **Фронтенд:** HTML5, CSS3, Vanilla JavaScript
*   **Кастомная разработка:**
    *   Собственный независимый плагин тренажеров `moneyneko-trainers-hub`.
    *   Дочерняя тема `astra-child` (для безопасной кастомизации интерфейса и серверной логики проекта).
*   **LMS и Геймификация:** Tutor LMS (система курсов), GamiPress (система баллов и рангов).

## 📂 Структура репозитория
Для поддержания чистоты архитектуры в данном репозитории хранится исключительно кастомный код проекта (ядро WordPress и тяжелые библиотеки исключены):

*   `/wp-content/themes/astra-child/` — основная логика интерфейса, шорткоды, кастомные страницы (профиль, лидерборд, главная страница с маскотом) и стили.
*   `/wp-content/plugins/moneyneko-trainers-hub/` — ядро интерактивной части. Плагин содержит независимые модули-тренажеры:
    *   `m1-sorting/` — тренажер сортировки чеков и расходов.
    *   `m2-cashflow/` — тренажер управления денежными потоками (Cash Flow).
    *   `m3-kiosk/` — симулятор принятия решений (Киоск).
    *   `m4-hidden-object/` — игра на поиск скрытых объектов в комнате.
*   `/wp-content/languages/loco/plugins/` — кастомные файлы локализации (переводы), созданные и настроенные командой через плагин Loco Translate.

## 🚀 Инструкция по развертыванию (Локально)
Для запуска проекта на локальной машине (например, через OpenServer) для разработки и тестирования:

1.  **Подготовка сервера:** Создайте локальный домен и разверните чистую установку WordPress.
2.  **Клонирование репозитория:**
    ```bash
    git clone [https://github.com/Cr0desON/moneyneko.git](https://github.com/Cr0desON/moneyneko.git)
    ```
3.  **Перенос файлов:** Скопируйте папки `themes`, `plugins` и `languages` из склонированного репозитория в вашу локальную директорию `wp-content`.
4.  **Синхронизация контента (База данных):** Запросите у команды актуальный дамп базы данных (`.sql`) и импортируйте его через phpMyAdmin.
5.  **Замена URL:** Используйте консольную утилиту WP-CLI для безопасной замены ссылок в базе данных с серверных на локальные (чтобы не сломать сериализованные данные):
    ```bash
    wp search-replace '[https://moneyneko.ru](https://moneyneko.ru)' 'http://ВАШ_ЛОКАЛЬНЫЙ_ДОМЕН'
    ```
6.  **Активация:** Зайдите в админку WordPress и убедитесь, что активирована дочерняя тема *Astra Child MoneyNeko* и плагин *MoneyNeko Trainers Hub*. Установите родительскую тему *Astra*, а также необходимые плагины (Tutor LMS, GamiPress, Loco Translate).
